# 管理画面 操作マニュアル

管理画面：**https://mpr-shop.com/nori2023/admin**（スマホからも操作できます）

ログイン：初回設定で登録したメールアドレスとパスワード
（5回続けて間違えると15分ログインできなくなります）

---

## 1. 完成品（1点もの）を登録する

1. **完成品（1点もの）→ ＋ 新しく登録**
2. 入力して **「登録して写真の追加へ」**

| 項目 | 説明 |
|---|---|
| 商品管理番号 * | ほかと重複しない番号。例：`KH-0001` |
| 商品名 * | 一覧と詳細ページに表示されます |
| カテゴリー | キーホルダー／コインケース など |
| 税込販売価格 * | 数字のみ（例：`8800`） |
| 説明文 | 改行はそのまま表示されます |
| 使用素材・サイズ・革の色 | 空欄の項目は表示されません |
| 送料設定 | 「送料設定」で登録した配送方法から選びます |
| URL用の名前 | 空欄なら商品管理番号から自動作成。公開後は変えないでください |
| 販売状態 | 下の表を参照 |
| 販売終了後のコメント | SOLD OUT のときだけ「おっさんからひとこと」として表示 |

> 登録直後は **非公開** です。写真を追加してから「販売中」にしてください（写真は **1枚以上** 必要。枚数の偶数・奇数は問いません）。

## 2. 写真を追加・並べ替える

- 商品の編集画面の **「＋ 写真を追加」** をタップ → カメラロールから選ぶ（複数可）
- 写真は自動で縮小されて保存されます（位置情報などは残りません）
- 各写真のボタン：**← →** 並び順／**★** メイン写真にする（一覧に出る写真）／**✕** 削除
- 写真の下の入力欄は **写真の説明（代替テキスト）** です。例：「赤いコインケースを開いたところ」
- 販売中の商品は、写真を0枚にはできません
- iPhone で失敗する場合：設定 → カメラ → フォーマット →「互換性優先」

## 3. 販売状態

| 状態 | お客様から見ると | 使いどころ |
|---|---|---|
| 非公開（下書き） | 見えない | 準備中 |
| 販売中 | 一覧・詳細に表示 | 公開するとき |
| 購入手続き中 | 「購入手続きしよります」と表示・購入不可 | 自動で切り替わります（手動では変更不可） |
| SOLD OUT | 写真に「SOLD OUT」、作品集に掲載 | 売れたとき（決済完了で自動。イベント等で売れた場合は手動で） |
| 販売停止 | 見えない | 一時的に取り下げるとき |

- **売れた商品は削除できません**（SOLD OUT作品集に残すため）
- **販売終了後のコメント**：SOLD OUT のときだけ、商品ページの「おっさんからひとこと」欄と作品集のカードに表示されます（300文字まで）。お客様のお名前や地域を載せる場合は、ご本人の了承をとってください

> 現在はオンライン購入（STEP 3）が未実装のため、「販売中」にしても購入ボタンは押せません。

## 4. 送料設定・カテゴリー

- **送料設定**：配送方法と送料（税込）を登録し、商品ごとに選びます。金額未定なら空欄に
- **カテゴリー**：表示名・URL用の名前（半角英小文字とハイフン）・並び順を変更できます

## 5. ページ設定

- **トップのメイン画像**：「画像を選んで変更」で差し替え。「初期画像に戻す」で元に戻ります
- **キャッチコピー・サブコピー**：キャッチコピーは「、」の後ろで改行して表示されます
- **制作者紹介の本文**：空行で段落が分かれます。空欄にすると初期の文章に戻ります

サイトの文章は広島弁で統一しています。変更するときも広島弁でお願いします。

## 6. Instagram 連携

トップページに @nori2023_ の最新投稿6件を画像付きで表示します（6時間ごとに自動更新）。

### 初回設定（1回だけ・約20分）

1. **Instagram をプロアカウントにする**（無料）
   Instagram アプリ → プロフィール → メニュー →「アカウントの種類とツール」→「プロアカウントに切り替える」→「クリエイター」または「ビジネス」
2. https://developers.facebook.com/ に Facebook アカウントでログイン →「マイアプリ」→「アプリを作成」→ 用途で **Instagram** に関するものを選ぶ
3. アプリの管理画面 →「Instagram」→「API setup with Instagram business login」→「アカウントを追加」で @nori2023_ を追加 →「トークンを生成」
4. 表示されたアクセストークン（`IGAA…` で始まる長い文字列）をコピー
5. 管理画面 **Instagram連携** → 貼り付けて **「登録して取得する」**
6. 「取得済みの投稿」に画像が並べば完了

- トークンの有効期限（60日）は自動で延長されます
- 表示が止まったら「今すぐ更新」を押し、エラーが出ていれば手順3〜5でトークンを登録し直してください

## 7. アカウント（パスワード変更）

**アカウント** 画面で、今のパスワードと新しいパスワード（10文字以上・英字と数字を含む）を入力します。

## 8. 操作履歴

誰が・いつ・何を変更したかを確認できます（直近200件）。

## 9. 困ったとき

| 症状 | 対処 |
|---|---|
| ログインできない | メールアドレス・パスワードを確認。5回失敗すると15分待つ必要があります |
| パスワードを忘れた | Claude に相談してください（データベースから再設定します） |
| 写真が追加できない | 通信環境の良い場所で再度。iPhone は「互換性優先」に。サーバーの php.ini 設定も確認（設置手順書 4.） |
| 「画面の有効期限が切れました」 | ページを開き直してから操作してください（長時間放置した場合に出ます） |
