# 管理画面 操作マニュアル

管理画面：`公開URL/admin`（スマホからも操作できます）

ログイン：メールアドレスを入力 → 届いた6桁のコードを入力（パスワードはありません）

---

## 1. 完成品（1点もの）を登録する

1. **完成品（1点もの）→ ＋ 新しく登録**
2. 入力して **「登録して写真の追加へ」**

| 項目 | 説明 |
|---|---|
| 商品管理番号 * | ほかと重複しない番号。例：`KH-0001` |
| 商品名 * | 一覧と詳細ページに表示されます |
| カテゴリー | キーホルダー／コインケース など |
| 税込販売価格 * | 数字のみ（例：`8800`） |
| 説明文 | 改行はそのまま表示されます |
| 使用素材・サイズ・革の色 | 空欄の項目は表示されません |
| 送料設定 | 「送料設定」で登録した配送方法から選びます |
| URL用の名前 | 空欄なら商品管理番号から自動作成。公開後は変えないでください |
| 販売状態 | 下の表を参照 |

> 登録直後は **非公開** です。写真をそろえてから「販売中」にしてください。

### 写真の枚数
「販売中」にするには、写真が **1枚以上** 必要です（枚数の偶数・奇数は問いません）。
販売中の商品の写真を全部消すことはできません。

## 2. 写真を追加・並べ替える

- 商品の編集画面の **「＋ 写真を追加」** をタップ → カメラロールから選ぶ（複数可）
- 写真は自動で縮小されて保存されます（位置情報などは残りません）
- 各写真のボタン
  - **← →**：並び順を変える
  - **★**：メイン写真にする（一覧ページに出る写真）
  - **✕**：削除
- 写真の下の入力欄は **写真の説明（代替テキスト）** です。目の不自由な方の読み上げや検索に使われます。例：「赤いコインケースを開いたところ」
- iPhone で失敗する場合：設定 → カメラ → フォーマット →「互換性優先」にしてください

## 3. 販売状態

| 状態 | お客様から見ると | 使いどころ |
|---|---|---|
| 非公開（下書き） | 見えない | 準備中 |
| 販売中 | 一覧・詳細に表示 | 公開するとき |
| 購入手続き中 | 「購入手続き中」と表示・購入不可 | 自動で切り替わります（手動では変更不可） |
| SOLD OUT | 写真に「SOLD OUT」、作品集に自動掲載 | 売れたとき（決済完了で自動。イベント等で売れた場合は手動で） |
| 販売停止 | 見えない | 一時的に取り下げるとき |

- **売れた商品は削除できません**（SOLD OUT作品集に残すため）
- **販売終了後のコメント**：SOLD OUT のときだけ、商品ページの「おっさんからひとこと」欄と作品集のカードに表示されます。300文字まで。お客様のお名前や地域を載せる場合は、ご本人の了承をとってください
- 削除できるのは「非公開」「販売停止」で、一度も売れていない商品だけです

> 現在（STEP 2 時点）はオンライン購入が未実装のため、「販売中」にしても購入ボタンは押せません。

## 4. 送料設定

**送料設定** で配送方法と送料（税込）を登録し、商品ごとに選びます。金額が決まっていない場合は空欄にしておくと、お客様には「購入手続き画面でご案内します」と表示されます。

## 5. カテゴリー

表示名・URL用の名前（半角英小文字とハイフン）・並び順を変更できます。

## 6. ページ設定

- **トップのメイン画像**：「画像を選んで変更」で差し替え。「初期画像に戻す」で元に戻ります
- **キャッチコピー・サブコピー**：キャッチコピーは「、」の後ろで改行して表示されます
- **制作者紹介の本文**：空行で段落が分かれます。空欄にすると初期の文章に戻ります

## 7. Instagram 連携

トップページに @nori2023_ の最新投稿6件を画像付きで表示します。6時間ごとに自動更新されます。

### 初回設定（1回だけ・約20分）

1. **Instagram をプロアカウントにする**（無料）
   Instagram アプリ → プロフィール → メニュー → **アカウントの種類とツール → プロアカウントに切り替える** →「クリエイター」または「ビジネス」
2. **Meta for Developers でアプリを作る**
   https://developers.facebook.com/ に Facebook アカウントでログイン → **マイアプリ → アプリを作成** → 用途で **Instagram** に関するものを選ぶ
3. アプリの管理画面 → **Instagram → API setup with Instagram business login**
   → **アカウントを追加** で @nori2023_ を追加 → **トークンを生成**
4. 表示されたアクセストークン（`IGAA…` で始まる長い文字列）をコピー
5. 管理画面 **Instagram連携** → 貼り付けて **「登録して取得する」**
6. 「取得済みの投稿」に画像が並べば完了。トップページ下部に表示されます

- トークンの有効期限（60日）は **自動で延長** されます
- 表示が止まった場合は **「今すぐ更新」** を押し、エラーが出ていれば手順3〜5でトークンを登録し直してください

## 8. 操作履歴

誰が・いつ・何を変更したかを確認できます（直近200件）。

## 9. 困ったとき

| 症状 | 対処 |
|---|---|
| 管理画面に入れない | 登録したメールアドレスでログインしているか確認。別のアドレスでは入れません |
| 「認証が未設定です」と出る | docs/DEPLOY.md の手順6が未完了です |
| 写真が追加できない | 通信環境の良い場所で再度。iPhone は「互換性優先」に |
| サイトが表示されない | 無料枠（1日10万アクセス）を超えた可能性。翌日 9:00 に回復します |
