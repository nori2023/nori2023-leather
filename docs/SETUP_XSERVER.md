# エックスサーバーへの設置手順（mpr-shop.com/nori2023）

所要時間の目安：30〜45分（ブラウザ操作のみ。FileZilla は使いません）

---

## 0. 事前確認：PHP のバージョン

このサイトは **PHP 8.1 以上** が必要です。

- サーバーパネル →「PHP Ver.切替」→ ドメイン `mpr-shop.com` の現在のバージョンを確認
- 8.1 未満の場合は切り替えが必要です。**mpr-shop.com のほかのページ（/order など）にも影響する** ため、切り替える前にほかのページの動作に問題がないか確認してください
- 古いままアップロードすると、ページに「PHP 8.1 以上が必要です」と表示されます（ほかには影響しません）

## 1. データベース（MySQL）を作る

サーバーパネル →「MySQL設定」

1. **MySQL追加** タブ：データベース名を入力（例：`xs123456_nori2023`）→ 文字コード **UTF-8（utf8mb4）** → 追加
2. **MySQLユーザ追加** タブ：ユーザー名（例：`xs123456_nori`）と **新しいパスワード** を決めて追加（パスワードはメモ）
3. **MySQL一覧** タブ：作ったデータベースの「アクセス権未所有ユーザ」から、作ったユーザーを選んで **追加**
4. 同じ画面に出ている **MySQLホスト名**（例：`localhost` または `mysqlXXXX.xserver.jp`）をメモ

> 既存のシステム（/order など）とは **別のデータベース** を作ってください。

## 2. プログラムをアップロードする

`nori2023` フォルダの中身を、サーバーの `mpr-shop.com/public_html/nori2023/` に置きます。方法は2つあります。

### 方法A：GitHub から自動アップロード（おすすめ）

一度設定すると、以後は Claude が GitHub に反映するだけで、自動でサーバーに届きます。

1. サーバーパネル →「SSH設定」→ **ONにする**
2. 同じ画面の「公開鍵認証用鍵ペアの生成」→ パスフレーズは **空欄** で生成 → 秘密鍵（`.key` ファイル）がダウンロードされる
3. GitHub のリポジトリ `nori2023/nori2023-leather` →「Settings」→「Secrets and variables」→「Actions」→「New repository secret」で、次の4つを登録

   | 名前 | 入れる値 |
   |---|---|
   | `XSERVER_HOST` | サーバーパネルの「サーバー情報」にあるホスト名（例：`sv12345.xserver.jp`） |
   | `XSERVER_USER` | サーバーID（例：`xs123456`） |
   | `XSERVER_SSH_KEY` | 手順2の `.key` ファイルをメモ帳で開いた中身すべて |
   | `XSERVER_PATH` | `/home/サーバーID/mpr-shop.com/public_html/nori2023` |

4. GitHub の「Actions」→「Deploy to Xserver」→「Run workflow」で初回アップロード

> **注意**：この鍵はエックスサーバーのアカウント全体に入れる鍵です。会社契約のサーバーの場合は、社内のルールに沿って扱ってください。不要になったら、サーバーパネルの SSH設定で鍵を削除できます。

### 方法B：サーバーパネルのファイル管理から手作業でアップロード

1. サーバーパネル →「ファイル管理」→ `mpr-shop.com/public_html/` を開く
2. 新しいフォルダ `nori2023` を作る
3. Claude から受け取った zip の中の **nori2023 フォルダの中身すべて**（`.htaccess` と `.user.ini` も含む）を、作ったフォルダにアップロード

> 更新のたびに同じ作業が必要になります。`app/config.php` と `uploads/` の中の画像は、上書き・削除しないでください。

## 3. 初回設定

1. ブラウザで **https://mpr-shop.com/nori2023/install** を開く
2. 入力する
   - **設置キー**：Claude から伝えた英数字12文字
   - **データベース**：手順1でメモしたホスト名・データベース名・ユーザー名・パスワード
   - **管理者**：ログインに使うメールアドレスとパスワード（10文字以上・英字と数字を含む）
   - **公開URL**：`https://mpr-shop.com/nori2023`
3. 「設定して始める」→ ログイン画面が出たら完了

以後 `/install` は表示されなくなります。設定内容は `app/config.php` に保存されます（ブラウザからは見られません）。

## 4. 動作確認

- https://mpr-shop.com/nori2023/ が表示される
- https://mpr-shop.com/nori2023/admin でログインできる
- 管理画面で商品を1つ登録し、写真を追加 → 販売中にして公開ページに出る

写真の追加でエラーになる場合は、サーバーパネル →「php.ini設定」で `upload_max_filesize` を `20M`、`post_max_size` を `25M` 以上にしてください（このフォルダの `.user.ini` でも設定していますが、効かない場合があります）。

## 5. Instagram の自動更新（任意）

トップページが表示されたとき、前回から6時間以上たっていれば自動で更新するので、設定しなくても動きます。より確実にしたい場合は、サーバーパネル →「Cron設定」で次を追加します。

```
分：0  時間：*/6  日：*  月：*  曜日：*
コマンド：/usr/bin/php8.2 /home/サーバーID/mpr-shop.com/public_html/nori2023/app/cron.php
```

（`php8.2` の部分は、手順0で確認した PHP のバージョンに合わせてください）

## セキュリティのまとめ

- `app/` フォルダ（プログラム・設定・DB接続情報）はブラウザから見られない設定（`.htaccess`）
- `uploads/` には画像（JPEG/WebP）以外は置けず、プログラムも動かない設定
- 管理画面：パスワードは暗号化して保存、5回失敗で15分ロック、すべての変更操作に改ざん防止トークン
- 初回設定は「設置キー」がないと実行できず、設定後は無効になる
